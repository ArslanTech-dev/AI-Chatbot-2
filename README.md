## 🧠 About The Project

```yaml
Project:      AI-Chatbot-2
Type:         AI Chat Web Application
Framework:    Next.js (App Router)
Language:     TypeScript
Styling:      Tailwind CSS
Architecture: API Routes + React Components
Status:       ⚡ Actively Evolving
```

**AI-Chatbot-2** 🚀✨ is a modern, full-stack **AI-powered chat web app** built with **Next.js 14+**, styled with **Tailwind CSS**, and structured with clean, scalable architecture — a proper leveled-up version of my earlier chatbot project. It runs entirely in the browser with a slick UI, talking to an AI backend through a dedicated API route. 💬🌐

Unlike a simple terminal script, this is a **real deployable web product** — fast, responsive, and ready to scale. 💪

## 🚀 Getting Started

### ✅ Prerequisites

- 🟢 [Node.js](https://nodejs.org/) v18 or higher
- 🟢 npm / yarn / pnpm package manager
- 🟢 An AI API key (OpenAI / Gemini / or your chosen provider)

### 📦 Installation

```bash
# 1️⃣ Clone the repository
git clone https://github.com/ArslanTech-dev/AI-Chatbot-2.git

# 2️⃣ Navigate into the folder
cd AI-Chatbot-2

# 3️⃣ Install dependencies
npm install

# 4️⃣ Set up your environment file
cp .env.local.example .env.local
# then edit .env.local with your real API key

# 5️⃣ Run the development server
npm run dev
```

<div align="center">
<img src="https://media.giphy.com/media/Rkoat5KMaZC7bh9DDZ/giphy.gif" width="420"/>
</div>

Open [http://localhost:3000](http://localhost:3000) in your browser 🌐 — and start chatting with your AI! 🤖💬

---

## ⚙️ Configuration

Set these values in your `.env.local` file (see `.env.local.example`):

| Variable | Description |
|---|---|
| `OPENAI_API_KEY` / `AI_API_KEY` | Your AI provider's API key |
| `NEXT_PUBLIC_APP_NAME` | Custom app name shown in the UI *(optional)* |

> 🔒 **Never commit your real `.env.local` file** — it's already excluded via `.gitignore`.
